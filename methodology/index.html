Methodology

Curated aggregates in, static HTML out.

The site is generated from Phase 1 `site-data` bundles, not from raw transcripts or arbitrary technique tables.

What gets published

  • Public corpus provenance and pinned dataset revisions.
  • Session and split-stratum counts.
  • Technique completion/error status for up to 23 techniques.
  • A fixed allowlist of aggregate findings.
  • Warnings for tiny cohorts, empty autonomous axes, language-axis gaps, and duplicate-shaped corpus families.

What does not

  • Raw transcripts, prompts, assistant messages, thinking text, or tool payloads.
  • Raw per-session tables, session ids, project names, or source paths.
  • Notebook artifacts unless a later phase explicitly allowlists them.

Current caveats

The compound scoping rule still applies: findings should be scoped by session type, thinking visibility, language, and time window. This first generated site shows deterministic corpus-level metrics; it is not yet the LLM interpretation layer and it is not a substitute for methodology review.

Reuse fingerprints

Each corpus bundle records corpus, process, and interpretation fingerprints. CI can reuse a previous public-safe bundle when the corpus and process fingerprints match; manual force runs can still rerun the whole thing when humans are feeling suspicious.
